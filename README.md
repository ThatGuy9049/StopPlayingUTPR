# StopPlayingUTPR, close brother of StopPlayingUCDR!

The ultimate tool for breaking the cycle and taking back your time
StopPlayingUTPR is a lightweight Chrome extension designed with one thing in mind:
Instantly closing any tab opening [Undertale Test Place Reborn](https://www.roblox.com/games/7491927311/Undertale-Test-Place-Reborn) on [Roblox](https://www.roblox.com) before you can fall back into the loop!

#  Key Features 

Checks Game ID 
Gives motivational message telling you to stop trying to play!
Fully Local!

# Why?
No one likes the state of game, and
Let's admit it, some people have habits of coming back to things they swore they'd stop playing. 

This should help with that!

# What it can't do
Stop you from launching the game via the Roblox App
Stop you from joining through friends
Stop you from starting the Roblox App with parameters to join the game.
Why?
Fix your lack of maidens
Because this is an extension.
